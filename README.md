# Power BI

Power BI is a Business Intelligence and Data Visualization platform developed by Microsoft. It is used to collect, transform, analyze, visualize, and share data through interactive dashboards and reports.

Power BI allows users to connect data from multiple sources such as Excel, CSV, SQL databases, APIs, and cloud services. Using Power Query, data can be cleaned and transformed before analysis. Power BI also provides DAX (Data Analysis Expressions) for creating calculated columns, measures, and custom business calculations.

### Key Features

-  Interactive dashboards and reports
-  Connection with multiple data sources
-  Data cleaning and transformation using Power Query
-  Data visualization using charts, graphs, KPIs, maps, and tables
-  Data analysis and calculations using DAX
-  Data modeling and relationships between tables
-  Interactive filters and slicers
-  Report publishing and sharing through Power BI Service
-  Dashboard access across different devices
-  Data security and controlled access

### Power BI Workflow


- Other business data sources

### Main Components

**Power BI Desktop**
Used to import data, clean and transform it, create data models, write DAX formulas, and build reports.

**Power Query**
Used for data extraction, cleaning, transformation, and preparation.

**DAX (Data Analysis Expressions)**
A formula language used to create measures, calculated columns, and analytical calculations.

**Power BI Service**
A cloud-based platform used to publish, share, manage, and collaborate on Power BI reports and dashboards.

### Business Applications
